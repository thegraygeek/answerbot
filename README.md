# 🤖 Answerbot

Answerbot is a full-stack AI assistant application designed to help users get answers in real-time using modern web technologies and AI models.

## 🔧 Tech Stack

- **Frontend:** React, TailwindCSS, Radix UI
- **Backend:** Express.js, WebSockets
- **Database:** PostgreSQL
- **ORM:** Drizzle ORM
- **Language:** TypeScript
- **Deployment:** Replit or GitHub Pages
- **Authentication:** Passport.js

## ✨ Features

- 🔍 Question answering with LLM integration
- 🧠 Retrieval-Augmented Generation (RAG)
- 🔄 Real-time messaging via WebSockets
- 📈 Analytics or dashboard support via Recharts
- 🧪 Fully typed with TypeScript for safety
- 🛡️ Secure session management and API routing

## 🛠️ Getting Started

### Prerequisites
- Node.js ≥ 18
- PostgreSQL database
- GitHub account

### Installation

```bash
git clone https://github.com/thegraygeek/answerbot.git
cd answerbot
npm install
```

### Running Locally

```bash
npm run dev
```

Set up `.env` file with:

```env
DATABASE_URL=postgres://<user>:<password>@<host>:<port>/<dbname>
SESSION_SECRET=your_session_secret
```

## 📦 Deployment

- Use Replit for instant deployment and preview.
- Or configure GitHub Pages + GitHub Actions.
